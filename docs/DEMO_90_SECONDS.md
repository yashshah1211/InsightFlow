# 90-second demonstration script

Record the actual app: https://insightflow-preview-demo.vercel.app/.
This file is a script, not a video. Rehearse once at a natural pace; target about
90 seconds including transitions. Do not invent screenshots or provider results.

Prepare the public modules and a separate pre-authenticated browser session using
the existing authored private acceptance batch/action. Keep login, account email,
passwords, cookies, developer tools, env files, private review sheets and billing
pages out of the recording. Mask the workspace ID if visible. Use retained data;
recording does not require new writes. If private access is unavailable, disclose
that the private segment is omitted rather than simulate a save.

| Time | Actual screen/action | Narration |
| --- | --- | --- |
| 0–10s | Command Center: fixture badge and raw/pattern counts | “InsightFlow turns noisy customer feedback into evidence and actions. This public demo has ten authored synthetic reviews: nine patterns and one repeat.” |
| 10–25s | Feedback: pattern view; search `not a victim of fraud`; evidence drawer | “TrustLens preserves every original row while grouping exact normalized text. Negation stays intact: a denied allegation is excluded from fraud evidence. Missing complaint dates stay unknown.” |
| 25–39s | Issue Intelligence: supported issue and source quotes | “Every issue has evidence, severity and a recommendation. Analysis is labeled heuristic; unsupported language and confidence are not invented.” |
| 39–53s | Decision Studio: objective switch and simulation sliders | “Safety, experience and operations use visible weights. Repetition has no direct scoring weight. These sliders explore hypothetical priorities, not predicted business results.” |
| 53–68s | Pre-authenticated session: select existing four-row batch; show saved action/status | “Private imports and actions persist in real Supabase storage. Users discover only their own batches; reciprocal isolation and logout were tested on this hosted app.” |
| 68–78s | Private Reports: correct batch briefing and CSV download | “Reports and exports follow the selected dataset and preserve provenance and limitations.” |
| 78–90s | Data Lab: integrity and unavailable run/evaluation states | “Adaption’s authenticated SDK connection and independently reviewed synthetic pilot are ready. Processing awaits billing assurance and approval. No run, trained model or accuracy gain is claimed.” |

Show all six real modules and keep the opening synthetic badge visible. Review
the completed recording for exposure before uploading its link. The video host,
format and length limit require organizer confirmation; 90 seconds is this
project's prepared demo, not a verified event rule.

Judges need no login for public screens. For private functionality, the owner can
operate a screen share or use organizer-approved dedicated reviewer access via
a private channel. Never publish test passwords in README/video/repository,
deployment variables or public form fields. New accounts/invitations are not
created by this packaging task.
